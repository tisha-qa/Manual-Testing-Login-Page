Manual Testing - Login Page

Project Overview

This project demonstrates basic manual testing of a login page, including test scenarios, test cases, and sample bug reporting.

Project Objectives

- Verify login functionality.
- Test valid and invalid credentials.
- Validate empty-field behavior.
- Document test cases and sample defects.

Project Files

- "Test-Scenarios.md" - Login testing scenarios.
- "Test-Cases.md" - Detailed test cases.
- "Bug-Reports.md" - Sample bug report.

Testing Types

- Functional Testing
- Positive Testing
- Negative Testing
- Validation Testing

Tools Used

- Git
- GitHub
- Manual Testing Documentation

Project Status

Documentation created. Test cases have not yet been executed against a real application.
